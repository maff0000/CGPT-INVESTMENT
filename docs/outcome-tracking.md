# Outcomes and learning
The goal is to measure whether the process produces useful research, not to retroactively manufacture a successful portfolio.

## Process measures
Track candidates discovered, reviewed, advanced, waiting and rejected; source completeness; gate failures; near-miss reasons; sector changes; and time to resolve key questions. Retain rejected and inactive names to reduce survivorship bias.

## Proposed prospective research measurement
Before collecting returns, declare start timestamp, observable reference price, benchmark, horizon, dividend/split treatment, currencies and methodology version. Suggested research horizons are 1, 4 and 12 weeks, pending adoption. A signal observed after the close cannot receive an earlier same-day executable price.

For a price-return study, return = end/reference price − 1, using consistently split-adjusted prices. Compare like-for-like benchmark returns over identical timestamps; excess return is the percentage-point difference. For total returns, explicitly include dividends consistently in both series. Record missing prices, mergers and delistings rather than dropping failures.

Research-watchlist performance is hypothetical and is not realised performance, a recommendation or an executed strategy. If a future model adds costs, slippage or rebalancing, define them before measuring. Do not publish private holdings or brokerage transactions.

## Review
Use [outcome template](../templates/outcome-review.md). Compare outcomes to the original thesis and invalidation criteria; log what was knowable then. No baseline prices or performance claims have been populated on 2026-11-03. Four weeks is a process check, not statistical validation.
