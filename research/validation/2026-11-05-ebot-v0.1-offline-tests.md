## What the automated tests cover
- Allowlisted prompt, including case, spacing, `as of`, and `and` before SPY.
- Rejection of other symbols, extra words, shell-like text, URLs, paths, and an impossible date. The shell is not called.
- Missing key, blank hidden prompt, command-line credential flag, mode `0644` key file, and a key path inside the git repository.
- Grouped and ticker paths match the existing probe. A sixth call is not sent. 401 fails. 403 and 429 hold and are not retried. Malformed JSON does not keep a body.
- 260 synthetic weekday bars can pass the count check. 259 bars, duplicates, unordered bars, a long weekday gap, and a malformed high/low hold. Sentinel prices are absent from the report.
- `$1.00` is `PRICE_OK`. `$1.01` is `PRICE_CHECK`. A pivot straddle is `SIGNAL_AMBIGUOUS` and blocks breakout confirmation. Session, currency, instrument, and adjustment mismatches are `DATA_MISMATCH`.
- The smoke report says `SECOND_SOURCE_NOT_TESTED` and does not invent a close comparison.
- A secret planted in an error or a status field is redacted or withheld.

The synthetic bars exist only in memory inside the tests. They are not a vendor extract.

## Open limits
- Live Massive access, the real timestamp unit, exchange holidays, and the account's two-year entitlement are untested. The local history guard is 731 days.
- Bar dates are the UTC calendar date of the provider timestamp, the same convention as `research/validation/g0_massive_readonly_probe.py`.
- A second source is required before any `PRICE_OK` or `PRICE_CHECK` result.
- Commercial licence, chart quality, and the shared 5-request-per-minute budget still block G0 acceptance.
- The undated sentence from the owner note is intentionally rejected. The dated allowlisted sentence is required.
