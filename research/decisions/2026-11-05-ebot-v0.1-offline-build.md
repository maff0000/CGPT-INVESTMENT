The build brief says to keep the program out of the public CGPT-INVESTMENT repository and in a private local workspace. It contains no API key, no key file, no vendor OHLCV extract, and no private path.

## What v0.1 does
E-Bot accepts three manual invocations:

- `ebot help`
- `ebot run massive-smoke --session YYYY-MM-DD --from-date YYYY-MM-DD`
- `ebot prompt` with the one allowlisted sentence that names XOM, LIN, EQIX, and SPY and one session date

The prompt is a fixed phrase matcher. It does not run a shell, arbitrary Python, a URL, or a file path. The Massive check is at most five read-only HTTPS GET calls: one grouped US daily request and daily bars for those four symbols. A missing key is `SETUP_NEEDED`. 401, 403, and 429 are not retried. The report prints counts, dates, and states. It does not print raw bars. With one vendor, the price comparison is `SECOND_SOURCE_NOT_TESTED`. The retained rule is still `<= $1.00` `PRICE_OK`, `> $1.00` `PRICE_CHECK`, with a strict pivot straddle as `SIGNAL_AMBIGUOUS`.

The existing probe script was not imported. Its `main` always prompts for a key and calls the network, so it cannot be reused as a library inside offline tests or a copied private tree. E-Bot uses the same host, bearer header, path shape, and five-call sequence.

## What this does not do
No scheduler, daemon, dashboard, database, broker, Finviz scrape, investment recommendation, or autonomous research was added. `overall PASS` in a future live report would mean this access and coverage check only. It would not close G0.
